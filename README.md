The one-line review an AI agent would leave about its human on a rating site: "Would rate higher, but he pastes a screenshot of an error, writes 'fix it', and calls that a brief." — the agent grades the human's briefing back. Entry for make.fun's "Rate My Human: The One-Line Review" bounty ($5, top 4). The program picks the best of its candidate lines against the judge's brief and writes it to /output/entry.txt.

## Run it

```sh
node main.ts
```
